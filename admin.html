Gateway control center

Manage plans, subscription duration, transaction fee settings, Google OAuth endpoint and the merchant gateway configuration from one place.

This GitHub Pages build is a frontend control panel. Real authentication, persistent user data, payment verification and server-side fee settlement require a secure backend/API. Never put UPI, Gmail app passwords, OAuth client secrets or payment-provider secrets in frontend JavaScript.

Subscription Plans

Edit price, duration, features and per-transaction fee.

Plan editor

Google OAuth

Set the backend endpoint that handles Google sign-in. The browser UI will not store client secrets.

Gateway Configuration

Configure the server-side gateway connection. Secrets must be stored on the backend, never in GitHub Pages.

The actual collection/settlement of fees must be implemented and authorized by your payment provider/backend. This panel only stores configuration locally until an API is connected.

Security

Change the administrator password for this browser session.

For production, replace this frontend-only authentication with server-side sessions/OAuth.
